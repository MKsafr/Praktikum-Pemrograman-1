File ZIP ada di WinIsle.zip. Folder unduhan updater: Updates. ZIP itu berisi paket versi 1.0.3 dan diunduh pada 11 November 2026.

Penyebabnya kemungkinan besar ada ketidakcocokan di updater: ZIP menyertakan scantext.ps1, tetapi WinIsleUpdater.ps1 menolak berkas itu karena tidak ada di daftar file yang diizinkan. Akibatnya updater membatalkan pemasangan. Saya juga memeriksa WinIsle.exe: versinya masih 1.0.2.0. Log error.log memuat kegagalan koneksi ke GitHub yang lebih lama, bukan catatan unduhan terbaru.

Untuk memperbarui sekarang: tutup WinIsle, unduh WinIsle-v1.0.3.zip dari halaman rilis, lalu ekstrak semua isinya ke folder tempat Anda menjalankan WinIsle.exe dan izinkan file ditimpa. Kalau Anda menjalankan EXE dari folder yang Anda berikan, folder tujuannya WinIsle-main. Setelah itu jalankan WinIsle.exe lagi.
